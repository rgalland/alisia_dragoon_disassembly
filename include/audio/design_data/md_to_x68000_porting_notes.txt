MD DAC (YM2612 channel 6):
  - Raw PCM samples written directly to register $2A
  - Z80 streams raw 8-bit unsigned PCM bytes at timed intervals
  - Sample rate controlled entirely by Z80 loop timing
  - No dedicated hardware — just a DAC register in the YM2612

X68000 MSM6258:
  - Dedicated ADPCM codec chip
  - Uses OKI ADPCM format (4-bit compressed, not raw PCM)
  - Hardware handles playback timing automatically
  - Separate clock input controls sample rate
  - DMA capable — can stream without CPU intervention
  
Startup conversion pipeline:
  MD raw 8-bit PCM samples
        ↓
  Convert to OKI ADPCM 4-bit at load time
        ↓
  Store in RAM sample pool

Playback:
  Game triggers via snd_sample/$0010
        ↓
  MSM6258 started with pointer + length
        ↓
  Hardware streams autonomously
  CPU only checks completion flag  
  
The two distinct areas
Instrument channel blocks — base $111A

4 blocks × 36 bytes ($24) each
Processed by sub_0dbeh each timer B tick
Triggered by $0012 instrument register
ix+$1b here = status flags (bit 0=active, bit 1=vibrato, bits 7-6=panning)
sub_0b3fh is NOT called from these — IY is loaded differently here

Music channel state blocks — base $11AA

9 blocks × 54 bytes ($36) each (6 FM + 3 PSG)
Processed by sub_03d1h each sequencer tick
Driven by track data loaded via $0005
ix+$1b here = preset pointer low byte
ix+$1c here = preset pointer high byte
sub_0b3fh IS called from these to load IY with preset address

snd_timer_irq:
    ; Check timer B flag (already our interrupt source)
    bsr     sub_01c9h_equiv     ; timer B handler
    bsr     sub_0137h_equiv     ; channel silence/reload if sample active
    tst.b   (snd_instrument)
    beq.b   .no_inst
    bsr     snd_load_instrument
.no_inst:
    rte
